# Contributing to this Wiki

## How to Contribute

This wiki is a community resource. Contributions of all kinds are welcome:

- **Content** — Write or improve articles
- **Corrections** — Fix errors or outdated information
- **Translations** — Translate pages into other languages
- **Peer review** — Fact-check medical information
- **Design** — Improve site layout or readability

## Guidelines

1. **Be accurate** — Cite sources for medical claims
2. **Be inclusive** — Write for a global audience
3. **Be clear** — Use plain language; avoid unnecessary jargon
4. **Stay neutral** — Present evidence-based information

## How to Submit Changes

This wiki is built with VitePress. To contribute:

1. Fork the repository
2. Make your changes
3. Submit a pull request
