# When to Stop / Seek Help

## Polycythemia (High Hematocrit) Warning

| Symptom | Notes |
|---------|-------|
| **Persistent headaches** | Can indicate high blood viscosity |
| **Dizziness / lightheadedness** | |
| **Blurred vision** | |
| **Fatigue / weakness** | |
| **Shortness of breath** | |
| **Chest pain** | |

If HCT > 54%, seek medical attention. Therapeutic phlebotomy may be needed.

## Pulmonary Embolism (PE)

| Symptom | Notes |
|---------|-------|
| Sudden shortness of breath | Call emergency services |

## Severe Depression / Suicidal Thoughts

- **US:** 988 (Suicide & Crisis Lifeline)
- **UK:** 111 or 999
- **Trans Lifeline:** [translifeline.org](https://translifeline.org)

## What NOT to Do

- ❌ Don't ignore symptoms
- ❌ Don't stop all HRT without a plan
- ❌ Don't lie to doctors about DIY HRT in emergencies
