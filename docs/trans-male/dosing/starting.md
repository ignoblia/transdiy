# Starting Doses (Beginner)

## Before You Start

Get a baseline blood test including:
- Total T, free T
- E2
- CBC (especially hematocrit)
- Comprehensive metabolic panel
- Lipid panel

## Starting Regimens

### Injectable Testosterone

| Ester | Starting Dose | Frequency |
|-------|---------------|-----------|
| T cypionate | 50 mg | Weekly |
| T enanthate | 50 mg | Weekly |

### Testosterone Gel

| Brand | Starting Dose |
|-------|---------------|
| AndroGel 1% | 25–50 mg/day |
| Testogel | 25–50 mg/day |

## Sample Regimens

```
T cypionate 50 mg IM weekly
```
or
```
T gel 50 mg daily
```

## When to Increase

- **After 4–8 weeks:** Check T levels at trough
- **Target:** 300–1,000 ng/dL
- If below target and tolerating well, increase dose by 25–50%
