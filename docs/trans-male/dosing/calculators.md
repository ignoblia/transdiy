# Dosage Calculators

## Injection Dose Equivalents

| Desired Weekly Dose | T Cypionate (mL of 200 mg/mL) | T Cypionate (mL of 100 mg/mL) |
|--------------------|-------------------------------|-------------------------------|
| 50 mg | 0.25 mL | 0.5 mL |
| 75 mg | 0.375 mL | 0.75 mL |
| 100 mg | 0.5 mL | 1.0 mL |

## Formula

```
Volume (mL) = Desired dose (mg) ÷ Concentration (mg/mL)

Example: 75 mg ÷ 200 mg/mL = 0.375 mL
```
