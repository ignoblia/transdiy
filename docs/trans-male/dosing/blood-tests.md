# Blood Tests — What & When

## Before Starting (Baseline)

| Test | Why |
|------|-----|
| Total T | Natural level |
| Free T | Baseline |
| E2 | Baseline |
| CBC (hematocrit) | Baseline before T stimulation |
| CMP | Liver/kidney function |
| Lipid panel | Baseline |
| Blood pressure | Separate but important |

## First Year (Every 3 Months)

| Test | Target |
|------|--------|
| Total T (trough) | 300–1,000 ng/dL |
| Free T | 50–200 pg/mL |
| E2 | < 50 pg/mL |
| CBC (HCT) | < 54% |
| Blood pressure | < 130/80 |

## After First Year (Every 6–12 Months)

| Test | Frequency |
|------|-----------|
| Total T, free T, E2 | Every 6 months |
| CBC, CMP | Annually |
| Lipid panel | Annually |
| Blood pressure | Every visit |

## Testing Tips

- **Test at trough** — just before next injection (for injectable T)
- **Test at consistent time** — same day of injection cycle
- **Test after 4–8 weeks** on a new dose
