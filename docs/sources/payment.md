# Payment Methods (Crypto, WISE)

## Payment Options

| Method | Privacy | Buyer Protection | Common For |
|--------|---------|-----------------|------------|
| **Bitcoin / crypto** | High | None | Most DIY orders |
| **WISE (TransferWise)** | Medium | Limited | International orders |
| **PayPal** | Low | Good | Limited (sellers rarely accept) |
| **Bank transfer** | Low | Limited | Some sellers |
| **Western Union** | Medium | None | Used by some sellers (scam risk) |

## Cryptocurrency Tips

- Use **Monero (XMR)** for maximum privacy
- If using Bitcoin, use a **privacy wallet** and a **coin mixer**
- Buy crypto from a **centralised exchange** then transfer to a private wallet
- **Never send directly** from an exchange to a vendor

## WISE Tips

- Use a **dedicated email** for WISE transactions
- Keep transaction notes vague ("supplements")

## Red Flags

- Seller who **only** accepts Western Union/MoneyGram
- Seller who refuses to use escrow for large orders
- Requests for payment in gift cards (always a scam)
