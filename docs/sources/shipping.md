# Shipping & Customs

## Shipping Considerations

| Factor | What to Know |
|--------|-------------|
| Customs risk | Estradiol is low-risk (non-controlled); T is higher risk (controlled) |
| Package size | Smaller, discreet packages attract less attention |
| Tracking | Always use tracked shipping |
| Delivery time | International: 2–8 weeks |
| Reshipment policy | Reputable vendors offer reshipment if lost/seized |

## Discreet Packaging

Many vendors offer:
- Plain packaging (no medication labels)
- Labelled as "supplements" or "skincare"
- Return address unrelated to medication

## If Package Is Seized

1. **Do not claim it**
2. **Do not sign for it**
3. **Do not admit anything** — ask for a lawyer
4. **Contact seller** — many will reship
5. **Keep a backup supply**

## Tips

- Use a separate email for orders
- Use a VPN when ordering
- Don't order large quantities (attracts attention)
- Check your country's personal importation limits
